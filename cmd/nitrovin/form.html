In an AI assistant (MCP)

nitrovin mcp is an MCP server over stdio with one tool, decode_vin. For Claude Desktop (~/Library/Application Support/Claude/claude_desktop_config.json on macOS, %APPDATA%\Claude\claude_desktop_config.json on Windows) and Cursor (~/.cursor/mcp.json) the entry is the same.

A local binary

Use the absolute path which nitrovin prints: desktop apps do not see your shell's PATH.

{
  "mcpServers": {
    "nitrovin": {
      "command": "/opt/homebrew/bin/nitrovin",
      "args": ["mcp"]
    }
  }
}

The Docker image

{
  "mcpServers": {
    "nitrovin": {
      "command": "docker",
      "args": ["run", "--rm", "-i", "ghcr.io/joshuasprow/nitrovin", "mcp"]
    }
  }
}

Verify a release

Releases are signed with cosign keyless signatures from GitHub Actions: every asset has an <asset>.sigstore.json bundle and a line in checksums.txt. {{if .Links.Tag}}From the directory you downloaded {{.Links.Tag}}'s assets to:{{else}}This build, {{.DecoderVersion}}, is not a release: set TAG to the release you downloaded.{{end}}

TAG={{with .Links.Tag}}{{.}}{{else}}vX.Y.Z{{end}}
cosign verify-blob --bundle checksums.txt.sigstore.json \
  --certificate-identity https://github.com/joshuasprow/nitrovin/.github/workflows/release.yml@refs/tags/$TAG \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com checksums.txt
sha256sum --check --ignore-missing checksums.txt
cosign verify ghcr.io/joshuasprow/nitrovin:$TAG \
  --certificate-identity https://github.com/joshuasprow/nitrovin/.github/workflows/release.yml@refs/tags/$TAG \
  --certificate-oidc-issuer https://token.actions.githubusercontent.com
